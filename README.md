# Premium IT Student Portfolio

A futuristic, premium digital portfolio website built with HTML, CSS, and vanilla JavaScript. Open [index.html](index.html) directly in a browser to view it locally.

## Included Experience
- Premium loading screen and animated cursor
- Interactive hero, about, skills, projects, services, education, certificates, achievements, and contact sections
- Three.js, GSAP, AOS, particles, Typed.js, vanilla tilt, and Swiper-powered interactions

## Run Locally
1. Open [index.html](index.html) in your browser, or
2. Serve the folder with a local static server such as `python -m http.server`
